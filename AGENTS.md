# Slew

VJ software for creative coders: Tauri v2, React, Three.js, and a dual-window architecture.

This is a mature project. Check `docs/BACKLOG.md` before proposing new work.

## Setup and development

```bash
npm install
npm run tauri:dev
```

## Verify changes

```bash
npm run test:run
npm run build
```

## Project guidance

Read the relevant documentation before changing established systems:

- `docs/ARCHITECTURE.md` — system and window architecture
- `docs/CONVENTIONS.md` — code style, imports, and implementation patterns
- `docs/PACKAGING.md` — builds and releases
- `docs/CONTROLLERS.md` — hardware controllers
- `docs/BACKLOG.md` — planned work
